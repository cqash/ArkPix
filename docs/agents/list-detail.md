# 列表、收藏与详情页（含查看器）

> 从 AGENTS.md 拆分。改动列表/瀑布流/收藏/详情页/查看器时阅读并同步更新本文档。

- 所有插画列表（推荐/动态/排行/搜索/标签/收藏/用户作品）统一使用 `IllustWaterfall` + `IllustCard`；页面只需提供 `fetchFirst(): Promise<IllustListPage>` 与可选 `reloadToken`（变更触发重载）
- `IllustWaterfall` 可选入参 `compareFn?: (a, b) => number`：提供时入库数据按之排序，分页追加后全量重排；切换排序由页面递增 `compareToken`（@Prop @Watch）触发已加载数据重排。到达序反转比较器 `compareArrivalReverse`（WeakMap 记录入库顺序，收藏"旧→新"用）由容器导出
- 卡片按真实宽高比展示（高/宽>3 降级方图）；数据入库时经 `MuteFilter` 过滤（屏蔽词/屏蔽作者/AI 过滤）并 `BookmarkStateStore.seedFromList` 播种
- **首页悬浮胶囊底栏（双分支，须显式去背板）**：API 26+ 支持沉浸光感时 HomePage 用**标准 Tabs** + `barFloatingStyle({barBottomMargin: 12, barSideMargin: 24, maskColor: Color.Transparent, systemMaterial: MaterialUtils.tabBarMaterial()})`（ArkUI 沉浸光感通道，折射/边缘光效/深浅色自适应，`FloatingTabBarStyle` 为 API 26+ 属性严禁进低版本分支）；低版本走 **HdsTabs** `barOverlap(true)` + `barFloatingStyle({ barBottomMargin: 12, gradientMask + systemMaterialEffect })`（@kit.UIDesignKit，HDS 材质通道 API 23+ 即渲染磨砂模糊，模拟器实测可见）。两分支共享 @Builder TabContents 与自定义文字 TabBuilder（悬浮样式仅支持 BottomTabBarStyle/CustomBuilder 两类），细节与能力探测见 docs/agents/immersive-material.md。HDS 分支去背板三件套：`.barBackgroundColor(Color.Transparent)` + `.barBackgroundBlurStyle(BlurStyle.NONE)`（barOverlap=true 会默认给 TabBar 节点 COMPONENT_THICK 模糊）+ `gradientMask: { maskColor: '#01F1F3F5', maskHeight: 1 }`（悬浮样式默认背板蒙层浅色 #CCF1F3F5 高=栏高+16vp，是"胶囊下奶白带子"的根因，高度不可为 0 只能置透明色）；列表页底部留白：IllustWaterfall 可选入参 `bottomInset`（首页四个列表页传 72，**由 footer 高度承载，勿改用 WaterFlow padding**——padding 会把内容裁剪在 padding 盒内，底部留下永久空白带透出页面底色 #F5F5F5，正好挡住胶囊沉浸背景且随下拉刷新位移，是"胶囊后白块"的根因），SearchPage 画师结果 List 用占位 ListItem 留白（同理勿用 List padding），SettingsPage 内容区留白在 Scroll 内层 Column padding 上（滚动内容内，无此问题）
- **底栏 Tab 再点回顶**：HomePage TabBuilder onClick 判定"点击项=当前项"时写 AppStorage `tabRetapToken`（值 `"<tabIndex>:<epochMs>"`，时间戳保证重复点击产生新值）；Recom(0)/Follow(1)/Rank(2)/Search(3) 各页 `@StorageLink('tabRetapToken') @Watch` 解析自身索引，匹配则递增本地令牌传给 IllustWaterfall 的 `@Prop @Watch scrollTopToken`（值变更即内部 Scroller `scrollEdge(Edge.Top)`，WaterFlow 以 `scroller` 构造参数挂载）
- **下拉刷新=经典布局+顶部小药丸**（勿回退 position 固定不跟手/悬浮药丸方案——药丸会垫在卡片底下）：Refresh 设 `builder: this.RefreshIndicator()`，子组件不加 position，下拉时列表整体下移腾出顶部刷新区（刷新中保持 refreshOffset(64) 高度），药丸渲染在刷新区内；`pullUpToCancelRefresh(true)` 刷新中上滑浏览自动取消收回；指示为 48vp 半透明白底圆角药丸内嵌 `Progress(ProgressType.Ring)` 32vp——`@State refreshState`（onStateChange 同步，Drag/OverDrag=进度态、Refresh=`ProgressStatus.LOADING` 菊花、Inactive/Done 隐藏）+ `@State refreshPullOffset`（onOffsetChange 同步驱动进度值，total=64）；clip + constraintSize(minHeight 48) 防塌缩（官方 Refresh 示例 6 模式）；参数 `refreshOffset(64)` + `maxPullDownDistance(96)` + `pullToRefresh(true)`，deprecated 的 `offset`/`friction` 已移除、`pullDownRatio` 不设保持系统动态阻尼；`onRefreshing`/`$$isRefreshing`/`refresh()` 数据流不变；**refresh() 刷新期间保留旧列表内容（勿回退 `dataSource.setItems([])` 清空）**——清空会叠加 loadInitial 的 isInitialLoading 触发全屏 LoadingView（"刷新弹全屏加载中"的根因），保留旧内容后新数据到达由 acceptPage(reset=true) 整体替换、失败时旧内容兜底不打扰
- **冷启动缓存直出**（推荐页）：IllustWaterfall 可选入参 `fetchCached: () => Promise<IllustListPage | null>`，aboutToAppear → `loadInitialWithCache()`：缓存命中先 `acceptPage(cached, true)` 立即渲染（照常走 MuteFilter/收藏播种）再 `refresh()` 后台刷新（isRefreshing=true 时 Refresh 自动展示顶部药丸），未提供/未命中走原 loadInitial 全屏 LoadingView；RecomPage 用既有 `recommend_cache` 表提供 fetchCached（`getRecommendCache`+`parseIllustListPage`，失败返回 null），fetchFirst 的网络失败缓存回退保留不变
- **卡片长按直接保存**（对齐 pixez，旧三项长按菜单已移除）：heavy 震动 → `longPressSaveConfirm`（下载设置页开关，默认关）开启时先 AlertDialog 确认 → 单页存 p0、多页逐页 isDownloaded 检测（命中弹"跳过已下载页/全部重新下载"）后全部 enqueue → autoBookmarkOnDownload 联动；ugoira 分流 enqueueUgoira（见 docs/agents/download-exif.md）。「屏蔽作者」已迁至详情页画师行长按菜单
- **卡片星标可交互**：右上角星标常显（♡浅灰/❤红/请求中灰），单击=快速收藏/取消（BookmarkStateStore toggle 语义），长按=heavy 震动+上抛 `onStarLongPress` → IllustWaterfall 根 Stack 内建 `BookmarkTagPanel` 缺省宿主（标签多选 chip+公开/私密切换，确认走 `star(illust, restrict, tags)`；空标签=普通收藏；标签加载失败可重试或无标签确认兜底）
- 收藏状态三态注册表 `BookmarkStateStore`：`Map<illustId, 0|1|2>`（未收藏/请求中/已收藏），变更时以**新 Map 引用**写入 `AppStorage['bookmarkStates']` 驱动 `@StorageLink` 刷新；star/unstar 含请求中锁、失败回滚、toast、详情缓存失效；`star(illust, restrict, tags=[])` 支持带标签收藏（addBookmark 既有 arrayFields tags 表单编码；标签列表 `GET /v1/user/bookmark-tags/illust` → `ApiService.getBookmarkTags`，模型 `BookmarkTag{name,count}` 在 models/Bookmark.ets）
- **收藏页"已删除"占位卡判删规则（R6，勿回退"不在第一页即判删"）**：BookmarkPage 判删须同时满足 restrict 匹配 + 全列表分页确认——①本地快照候选先按 `snapshot.restrict === this.restrict` 过滤（restrict 空串按 public 对待），公开/私密 Tab 不交叉；②fetchFirst 返回纯 API 数据不插占位，后台 `classifyDeletedSnapshots(nextUrl, apiIds)` fire-and-forget 走查（仅存在该 restrict 存活快照候选时）；③复用 `apiService.fetchNext`+`parseIllustListPage` 逐页收集 id，**上限 20 页**，完整走完（nextUrl 空）后缺席快照才确认删除 → 构造占位 Illust 存 `@State confirmedPlaceholders` → `reloadToken++` 重载，fetchFirst 检测非空前置插入（占位卡进页数秒后出现属预期延迟）；④走查中途异常或超 20 页上限 → 静默放弃不插入任何占位卡（宁漏勿误），置 `classifyDone=true` 本轮会话不再重试；⑤防 reload 循环：插入占位后本轮不再触发走查（classifyDone 标志）；restrict 切换重置 confirmedPlaceholders/classifyDone 并递增 classifyGen（在途走查逐页检测代数变化即作废，pending 请求链式补跑新 Tab）
- **详情页 = 壳 + Pane**：壳 `pages/detail/IllustDetailPage` 解析路由参数 `{illustId, contextToken?, contextIndex?}`——无 token=渲染单 `IllustDetailPane`（非列表入口行为不变）；有 token=Swiper+LazyForEach（cachedCount 1，DetailIdDataSource 承载 id 序列），每 Pane 独立 `new IllustDetailStore()`、`isActive` 门控懒加载，接续登记由壳按当前 illustId 统一管理；滑至倒数第 2 项且上下文 nextUrl 非空时自动预取（fetchNext 闭包走 MuteFilter 过滤，追加写回 Registry+数据源），尾部占位页三态（转圈/失败重试/No More）。上下文来自 `DetailListContextRegistry`（模块级 Map 纯内存，上限 8），注册入口三处：IllustWaterfall 默认 onCardClick、IllustDetailPane 相关作品点击（快照 relatedIllusts+relatedNextUrl，fetchNext 闭包自持局部游标不引用原 store）、HistoryPage 浏览历史点击（nextUrl='' + 空页 fetchNext，末尾自然 No More；搜索历史 pid 回放保持单作品不注册）
- **详情页相邻作品预取（R7）**：Pane 可选回调 `onDetailLoaded`（缓存命中渲染后或 `store.load` 返回 true 时触发），壳 `prefetchNeighbors(currentIndex)` 对 index±1 静默预取（与 cachedCount 深度对齐）；数据走 DB 详情缓存路径（命中→仅补首图，未命中→`apiService.getIllustDetail`→`db.setIllustDetailCache`），首图 `prefetchCachedImage(pickDetailUrl(illust, 0, userSettingStore.getSettings().detailQuality))`——**档位必须取当前 detailQuality 设置**，否则激活时不命中；`neighborPrefetchedIds` Set 会话级去重（异常/无效数据移除允许下次重试），`prefetchGen` 代数每次触发递增、在途预取每个 await 后校验代数变化即中止（快速连滑防请求堆积，中止/成功有 console.info 日志）；**红线：预取绝不走 `IllustDetailStore.load()`**（会写浏览历史污染未看过的作品），也不 seed 收藏注册表、不弹 toast 等任何可见副作用；仅 contextToken 模式启用（单作品模式短路）；与末尾续页 `prefetchNext()` 并存互不干扰。**R8 缓存优先渲染（勿回退"命中仍等网络"）**：`store.load` 已拆 `loadFromCache`（纯 DB 读+收藏对账，不发网络不写历史无副作用）与 `refreshFromNetwork`（API→对账→落缓存→写历史，404 快照/errorMessage 语义不变），`load` = 两段串联对外行为兼容；Pane `loadDetail` 非 forceRefresh 时先 `loadFromCache`——命中**立即渲染**（渲染链+`db.addHistory` 写历史，用户已在看，先删后插幂等）并**立即触发 onDetailLoaded**（相邻预取不等网络，FR-046），再后台 `refreshFromNetwork` 静默刷新 UI（失败保留缓存内容，不弹错误页/toast，FR-048）；未命中/forceRefresh 走原全量路径（404 快照兜底/错误页不变）。历史"R7 预取生效但滑动仍转圈"的根因即旧 load 命中缓存仍 await 网络
- **详情页屏蔽占位**：Pane 加载完成后 `MuteFilter.isMuted(illust, settings)` 命中且组件级 `tempRevealed=false` → 整页占位（🚫 提示 + "临时查看"置 tempRevealed=true + "查看屏蔽设置"跳 MutePage）；临时查看仅本次会话不持久化；占位态隐藏 FAB
- 详情内容（`IllustDetailPane`）= 单 `List` 行模型（image 行×pageCount + info 行 + related_header 行 + related 行，每个 related 行装 3 个作品），数据编排在 `IllustDetailStore`；多页查看器 `ImageViewerPage` = `Swiper + ZoomableImage`
- **ZoomableImage 手势方案（禁止回退条件手势组）**：`GestureGroup(Parallel, Pinch+Pan+Tap)` 静态常驻挂载；`PinchGesture({fingers:2, distance:1})`；`PanGestureOptions.setDistance()` 动态更新 distance（scale=1→50vp 让位 Swiper 翻页，scale>1→3vp 跟手平移），在 `applyScale()` 末尾调用；`.priorityGesture()` 绑定手势组（优先于 Swiper 内置手势）；拖到 X 向边界继续外拖时 `onZoomChange(false)` 释放回 Swiper，松手恢复；契约回调为 `onZoomChange(isZoomed)`，父级 `Swiper.disableSwipe` 直接绑定该标志；双击 1↔2.5 切换，限幅 1~5 + 边界钳制；`@Prop @Watch('onUrlPropChange') url` 支持外部 URL 变更重载（查看器 HD 切换重置缩放状态）
- **ImageViewerPage 底栏（R5 pixez 化重排，替代 R4 胶囊栏）**：顶部工具栏已移除，返回/保存并入底部单行图标栏（Row width 100% + SpaceEvenly + hitTestBehavior Transparent + 底部安全区 padding + rgba(0,0,0,0.25) 淡底，遮罩态下保持可用）：①复制图片（SVG 双叠方框）——`imageCacheService.getLocalPath(当前URL)` 取缓存文件 → `ClipboardUtils.copyImage`（createImageSource→createPixelMap→pasteboard MIMETYPE_PIXELMAP，setData 后 release），任一失败回退 copyText(URL)+toast"已复制图片链接"；②页码指示（仅多页）；③返回（Text('‹') router.back()）；④全屏开关（SVG 四角图标，全屏中半透明）——`window.getLastWindow` + `setSpecificSystemBarEnabled('status', !fullScreen)`，aboutToDisappear 强制恢复状态栏；⑤保存=SaveButton icon-only（`SaveButton({icon: SaveIconStyle.FULL_FILLED})` 不带 text，授权逻辑不变；安全控件勿换普通按钮）；⑥分享当前页图片——`shareCurrentImage()`：`resolveSharePath()` 复用 R4 缓存路径解析（当前档位 URL→getLocalPath→fs.accessSync，未命中回退另一档）→ ShareKit systemShare 面板，SharedRecord 用 **image utd + `fileUri.getUriFromPath(path)` 的 uri 字段**（官方"分享图片"方案，扩展名取自缓存文件名经 `utd.getUniformDataTypeByFilenameExtension`，缺省 '.jpg'）；未缓存/异常 → `@State shareEnabled` 置灰（opacity 0.4）+ toast"图片加载后可分享"，进页/切页/切档时 `refreshShareEnabled()` 静默刷新；ugoira 时分享已下载 GIF（未下载置灰提示）；分享面板目标应用由目标应用声明决定（不接受图片类型的应用不出现）；⑦HD 切换（描边"HD"文本，showOriginal 原图档反色高亮）——当前页 URL=showOriginal?downloadUrls[i]:urls[i]，ZoomableImage @Watch 自动重载，ugoira 隐藏；图标统一白色 20~22vp（**sys.symbol 名称禁止猜测**，本页图标均 SVG 资源或 Text 字符），除 SaveButton 外点击均 HapticUtils.selectionClick()；**小尺寸自绘图标勿用 Shape/Path（尺寸渲染不可控，R5b「Shape 禁叠 padding」与 R5c「Path 显式尺寸」两次修复均失败，图标仍约 1/3 大小），一律用 SVG 矢量资源（resources/base/media/*.svg，24×24 viewBox、stroke #FFFFFF、仅基础 path/rect/line/polyline，不用 CSS/渐变/滤镜）+ `Image($r(...)).width(22).height(22)`**（R5d 终案：ic_viewer_copy / ic_viewer_fullscreen / ic_viewer_share，padding/opacity/onClick 挂外层 Column 容器）；底栏勿加 systemMaterial 沉浸光感（该区域材质不生效会渲染为透明，已回退 rgba 淡底，见 docs/agents/immersive-material.md）
- 用户主页统计字段在 `/v1/user/detail` 响应的 `profile` 对象内（非 user 对象）：`User.ets` 的 `ProfileStats` + `profileStatsFromJson()` 解析（totalFollowUsers/totalIllusts/totalManga/totalIllustBookmarksPublic）
