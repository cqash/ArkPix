# Feature Specification: FAB 与下载增强（fab-download-enhancements）

**Created**: 2026-07-27  
**Status**: Draft  
**Input**: User description: "1、收藏框应该为收藏为白色轮廓♥，收藏完成才是红色♥，下载用蓝色下箭头↓；2、图片下载支持多线程下载（多任务并发），设置中增加选项，最大5线程，默认3线程；3、详情页要有图片发布日期显示；4、搜索uid/pid的入口没了（回归）；5、下载按钮单击下载全部，长按弹窗可选择下载哪些图（小缩略图展示）；6、历史的搜索历史应该包含tag跳转"

## Overview

对详情页 FAB 操作区与下载能力做一轮增强与修复：FAB 视觉规范（轮廓心/红心/蓝色下载箭头）；图片下载支持可配置的多任务并发（1-5，默认 3）；详情页展示发布日期；修复搜索页 PID/UID 数字直达入口消失的回归；下载 FAB 改为"单击下载全部、长按弹缩略图选页"；tag 点击跳转搜索也写入搜索历史。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - PID/UID 数字直达入口回归修复 (Priority: P1)

搜索页输入纯数字时，建议区顶部重新出现"插画 ID 直达"和"画师 ID 直达"两个入口（该功能在上一轮搜索页改造后消失，属回归），点击分别直达作品详情/用户主页，且直达行为照常写入搜索历史（pid/uid 类型）。

**Why this priority**: 已交付功能消失，主路径受损。

**Independent Test**: 输入纯数字→两个直达入口出现→点击分别到达详情页/用户主页→历史页有 pid/uid 记录。

**Acceptance Scenarios**:

1. **Given** 搜索框输入纯数字，**When** 查看建议区，**Then** 顶部显示"插画 ID 直达"与"画师 ID 直达"
2. **Given** 直达入口可见，**When** 点击任一入口，**Then** 跳转对应页面且搜索历史新增对应类型记录
3. **Given** 输入非数字，**When** 查看建议区，**Then** 不显示直达入口
4. **Given** 输入数字后提交搜索或切换 Tab，**When** 操作结果区，**Then** 插画/画师双 Tab 功能无回归

---

### User Story 2 - FAB 视觉规范与下载交互改造 (Priority: P1)

收藏 FAB：未收藏时显示白色轮廓心形图标，收藏中/已收藏显示红色实心心形（请求中态沿用现有着色逻辑）。下载 FAB：蓝色圆形底 + 白色下箭头图标。下载 FAB 交互改造（仅多页作品）：**单击=下载全部页**；**长按=弹出页面选择弹窗**——弹窗内以小缩略图网格展示各页，可多选（全选/单选切换），确认后下载选中页，有重复下载检测沿用现有逻辑。单页作品保持现有行为：单击保存该页，长按不弹窗。

**Why this priority**: 用户明确的交互修正（当前单击只存第一页、长按出菜单不符合"一键收全图"的主诉求）。

**Independent Test**: 多页作品单击下载 FAB→全部页进入下载；长按→缩略图选页弹窗→选 2 页下载→仅这 2 页被下载；未收藏时 FAB 为轮廓心、收藏后变红心。

**Acceptance Scenarios**:

1. **Given** 未收藏作品详情页，**When** 查看收藏 FAB，**Then** 显示白色轮廓心形
2. **Given** 收藏成功后，**When** 查看收藏 FAB，**Then** 显示红色实心心形；取消收藏恢复轮廓心
3. **Given** 打开详情页，**When** 查看下载 FAB，**Then** 蓝色圆形底 + 白色下箭头
4. **Given** 多页作品，**When** 单击下载 FAB，**Then** 全部页进入下载流程（沿用重复检测）
5. **Given** 多页作品，**When** 长按下载 FAB，**Then** 弹出页面选择弹窗：小缩略图网格、每页可勾选、含全选/取消全选能力
6. **Given** 选页弹窗中选择了部分页，**When** 点击确认，**Then** 仅选中页进入下载；取消则不下载
7. **Given** 单页作品，**When** 单击下载 FAB，**Then** 保存该页；**When** 长按，**Then** 不弹出选页弹窗
8. **Given** 选页弹窗中某页已下载过，**When** 确认下载，**Then** 沿用现有重复下载确认逻辑
9. **Given** 选页弹窗未选择任何页，**When** 点击确认，**Then** 提示未选择或不响应，不发起空下载
10. **Given** 选页弹窗打开，**When** 长按某缩略图并滑动经过其他缩略图，**Then** 滑动路径经过的缩略图被连续批量选中（以起始格的选中状态切换方向为准，经过格与起始格同向变更）

### User Story 3 - 图片下载多任务并发（可配置线程数）(Priority: P2)

下载服务支持多任务并发：同时下载的图片任务数可在设置中配置（1-5 线程，默认 3，TextPickerDialog 多值选择沿用现有模式）。超出并发数的任务排队等待，有任务完成后自动启动排队任务。下载管理页可看到排队/下载中状态。配置即时生效（进行中的任务不受影响，新启动的任务遵守新上限）。

**Why this priority**: 批量收图效率提升，但现有串行下载可用，非阻塞。

**Independent Test**: 设置并发为 3 → 多页作品下载全部（如 10 页）→ 下载管理页看到最多 3 个任务同时下载中、其余排队，陆续完成。

**Acceptance Scenarios**:

1. **Given** 设置→下载组新增"下载线程数"选项，**When** 查看默认值，**Then** 为 3；可选范围 1-5
2. **Given** 线程数设为 3，**When** 发起 6 页下载，**Then** 同时下载中任务 ≤3，其余排队，完成后自动补位
3. **Given** 线程数设为 1，**When** 发起多页下载，**Then** 任务逐个串行完成
4. **Given** 下载中途修改线程数，**When** 新任务启动时，**Then** 按新上限执行；进行中任务正常完成
5. **Given** 应用重启后有排队任务，**When** 打开应用，**Then** 沿用现有"残留下载任务重置为 failed"行为，不自动恢复排队

---

### User Story 4 - 详情页展示发布日期 (Priority: P2)

详情页信息区统计区（收藏数/浏览数附近）展示作品发布日期+时间（如 2024-05-18 14:32，pixez 同款短格式），数据来自 Illust.createDate（模型已有字段，UI 未展示）。

**Why this priority**: 纯展示性增强，成本低。

**Independent Test**: 打开任意作品详情→统计区可见发布日期时间，与 Pixiv 网页版一致。

**Acceptance Scenarios**:

1. **Given** 打开任意作品详情页，**When** 查看统计区，**Then** 显示发布日期+时间（YYYY-MM-DD HH:mm 格式）
2. **Given** createDate 字段缺失/异常，**When** 渲染，**Then** 不显示该行或显示占位，不崩溃

---

### User Story 5 - 搜索历史包含 tag 跳转 (Priority: P2)

详情页点击 tag 跳转 TagSearchPage 时，该 tag 关键词写入搜索历史（类型 illust，与搜索框提交同类型）。历史页搜索历史 Tab 中此类条目点击回放行为与现有 illust 类型一致（TagSearchPage 执行该词搜索）。

**Why this priority**: 补齐搜索历史覆盖面的收尾项。

**Independent Test**: 详情页点任意 tag→历史页搜索 Tab 出现该 tag 记录→点击回放该 tag 搜索。

**Acceptance Scenarios**:

1. **Given** 详情页点击某 tag，**When** 打开历史记录页搜索历史 Tab，**Then** 该 tag 关键词已记录（illust 类型）
2. **Given** 搜索历史中有 tag 跳转记录，**When** 点击该条目，**Then** 以该词执行插画搜索
3. **Given** 同一 tag 多次点击跳转，**When** 查看搜索历史，**Then** 按既有去重规则（keyword+search_type）只有最新一条

---

### Edge Cases

- 选页弹窗缩略图加载失败：显示占位图，不影响勾选
- 选页弹窗在防社死模式下：缩略图沿用遮罩规则（R18 页显示遮罩样式）
- 多线程并发与现有重复下载检测（isDownloaded）的竞态：同一页不会被并发重复下载
- 并发任务与下载管理页轮询刷新的兼容性：多任务状态并发变化时列表正确反映
- 直达入口回归修复后，输入数字时自动补全/历史建议区布局不挤压
- 发布日期时区：按设备本地时区格式化
- FAB 在选页弹窗打开时隐藏（与其他弹层一致）

## Requirements *(mandatory)*

### Functional Requirements

**直达回归**
- **FR-101**: 搜索页纯数字输入 MUST 显示"插画 ID 直达/画师 ID 直达"建议入口，点击直达并写搜索历史（pid/uid）

**FAB 视觉与交互**
- **FR-201**: 收藏 FAB 未收藏 MUST 显示白色轮廓心，已收藏 MUST 显示红色实心心；下载 FAB MUST 为蓝色底+白色下箭头
- **FR-202**: 多页作品下载 FAB 单击 MUST 下载全部页；长按 MUST 弹出缩略图选页弹窗（多选/全选/确认/取消）
- **FR-203**: 单页作品下载 FAB 单击保存该页，长按不弹窗
- **FR-204**: 选页弹窗确认 MUST 仅下载选中页，沿用重复下载检测；空选择 MUST 不发起下载
- **FR-205**: 选页弹窗打开时 FAB MUST 隐藏（与现有弹层规则一致）

**多任务并发**
- **FR-301**: 设置 MUST 提供下载线程数选项（1-5，默认 3）
- **FR-302**: 下载服务 MUST 按配置并发执行任务，超限任务排队，完成自动补位
- **FR-303**: 配置变更 MUST 对新启动任务即时生效

**发布日期**
- **FR-401**: 详情页统计区 MUST 展示发布日期+时间（YYYY-MM-DD HH:mm，本地时区）

**搜索历史**
- **FR-501**: 详情页 tag 点击跳转 MUST 写入搜索历史（keyword=tag 名，search_type='illust'，走既有去重）

### Key Entities

- **下载队列**：任务状态扩展（排队中/下载中/完成/失败），并发上限来自设置
- **选页弹窗状态**：每页 {页码, 缩略图 URL, 是否选中}
- **AppSettings 扩展**：downloadThreadCount: number（默认 3，范围 1-5）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 纯数字输入时直达入口 100% 出现，直达与历史记录正确率 100%
- **SC-002**: 多页作品单击下载 FAB 后，全部页 100% 进入下载队列
- **SC-003**: 选页弹窗确认后下载页数与选中数 100% 一致
- **SC-004**: 设置 3 线程时，任意时刻下载中任务数 ≤3 且 ≥1（队列非空时），无任务丢失
- **SC-005**: 发布日期显示准确率 100%（与 Pixiv 网页一致）
- **SC-006**: tag 跳转的搜索历史记录覆盖率 100%

## Assumptions

- 多线程=多任务并发（非单文件分段），Pixiv 图片为独立文件无需 Range 支持
- 排队任务不持久化：应用重启后排队任务按现有规则重置为 failed（与 downloading/pending 一致）
- 选页弹窗缩略图用 CachedImage（沿用图片头处理）
- 防社死模式下选页弹窗的 R18 缩略图沿用纯色遮罩+锁图标样式（不可点击揭示，弹窗内仅作选择）
- FAB 图标用系统符号或文本符号实现（♥/↓ 风格 emoji 或 SymbolGlyph），不引入图片资源
- 发布日期显示行位置：统计区（收藏数/浏览数行附近），具体行序实现时定
