# Feature Specification: API 26 升级与沉浸光感适配

**Created**: 2026-09-28  
**Status**: Draft  
**Input**: User description: "更新到最新的鸿蒙系统api，适配沉浸光感相关功能"

## Overview

将 ArkPix 应用的编译/目标 SDK 升级到最新的 HarmonyOS 6.2.0(API 26)，并接入 ArkUI「沉浸光感」能力：通过 module.json5 应用级开关让系统组件（Dialog/Toast/菜单等）默认获得沉浸式系统材质，同时对查看器底栏、详情页顶栏、FAB 等重点浮动组件做组件级材质适配。最低兼容版本保持 6.1.0(23)，沉浸光感仅在 API 26+ 设备上生效，低版本设备自动降级、行为与现状一致。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 应用级沉浸光感生效 (Priority: P1)

用户在运行 API 26+ 系统的设备上使用 ArkPix，触发 Toast 提示、长按弹出上下文菜单、弹出确认对话框等系统组件时，这些组件呈现沉浸式系统材质（毛玻璃质感、通透背景、高算力设备上的弹出动效），无需逐页改动即获得统一的系统级视觉升级。

**Why this priority**: 应用级开关是沉浸光感接入的基石，一行配置即可覆盖全应用系统组件，投入产出比最高，且是所有后续组件级适配的前提（ENABLE 模式）。

**Independent Test**: 在 API 26+ 设备上启动应用，触发一次 Toast（如复制 PID）和一次长按菜单（如详情页 tag 长按），观察其呈现材质效果即可独立验证；不依赖任何组件级适配。

**Acceptance Scenarios**:

1. **Given** 应用已在 module.json5 配置应用级开关且设备系统 ≥ API 26，**When** 触发 Toast/上下文菜单/AlertDialog，**Then** 对应组件呈现沉浸式系统材质效果
2. **Given** 设备系统为 API 23~25，**When** 触发同样的 Toast/菜单/对话框，**Then** 组件表现与升级前完全一致，无崩溃、无样式异常

---

### User Story 2 - 图片查看器底栏沉浸光感 (Priority: P2)

用户在图片查看器（ImageViewerPage）中浏览图片时，底部单行图标栏（复制/页码/返回/全屏/保存/分享/HD）呈现超薄沉浸式材质，背景图片透过底栏呈现通透质感，取代现有的半透明纯色底。

**Why this priority**: 查看器底栏悬浮在全屏图片之上，是通透感收益最大的场景（内容相关的毛玻璃模糊直接作用于图片背景），也是当前有明显半透明纯色底（rgba(0,0,0,0.25)）可替换的位置。

**Independent Test**: 打开任意作品进入图片查看器，观察底栏材质效果并逐项点击图标确认功能不受影响即可独立验证。

**Acceptance Scenarios**:

1. **Given** 设备系统 ≥ API 26 且已进入图片查看器，**When** 查看底栏，**Then** 底栏呈现超薄（ULTRA_THIN 级别）沉浸式材质，背景图片透出
2. **Given** 底栏已应用材质，**When** 点击复制/返回/全屏/保存/分享/HD 各按钮，**Then** 全部功能与升级前一致
3. **Given** 设备系统为 API 23~25，**When** 进入图片查看器，**Then** 底栏保持现有半透明纯色底样式，功能不受影响

---

### User Story 3 - 详情页顶栏与 FAB 沉浸光感 (Priority: P3)

用户在作品详情页看到顶部药丸按钮（返回「‹」、菜单「⋮」）与右下角双 FAB（收藏、下载）呈现沉浸式材质与按压交互反馈，悬浮在内容之上时具有通透层次感。

**Why this priority**: 详情页是用户停留时间最长的页面，顶栏与 FAB 是高频交互点；但相比 P1/P2，其视觉收益与改动面居中，列为 P3。

**Independent Test**: 打开任意作品详情页，观察顶栏药丸按钮与 FAB 的材质效果，点击/长按验证交互不变，即可独立验证。

**Acceptance Scenarios**:

1. **Given** 设备系统 ≥ API 26 且已进入作品详情页，**When** 查看顶栏药丸按钮与右下角 FAB，**Then** 呈现沉浸式材质效果（按压有弹性形变/光感反馈）
2. **Given** 顶栏与 FAB 已应用材质，**When** 点击返回/菜单/收藏/下载及长按 FAB，**Then** 全部既有交互（含长按带标签收藏、长按选页弹窗）行为不变
3. **Given** 设备系统为 API 23~25，**When** 进入详情页，**Then** 顶栏与 FAB 保持现有样式与交互，无异常

---

### Edge Cases

- 设备系统低于 API 26：所有沉浸光感调用必须跳过/降级，不出现 API 不可用崩溃或样式丢失。
- 用户将系统沉浸光感强度设为「弱」或设备为低算力档位：系统自动降级材质表现，应用无需额外处理，但适配实现不得阻碍该降级。
- 材质与既有样式的冲突：已设置材质的重点组件不得再叠加 backgroundBlurStyle/shadow 等冲突属性（防止重复计算与视觉异常）。
- 应用级开关 ENABLE 后，个别不希望默认开启材质的系统组件（如特定 Select/Chip 场景）需可单独关闭。
- WebView 登录页涉及同层渲染的场景不支持沉浸光感，不得在该场景强制启用。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 项目编译与目标 SDK 版本必须升级到 6.2.0(API 26)，最低兼容版本必须保持 6.1.0(API 23) 不变。
- **FR-002**: 应用必须在 module.json5 配置应用级沉浸光感开关（ENABLE 模式），使支持的系统组件（Dialog/Toast/菜单控制/Select/Chip 等）在 API 26+ 设备上默认开启沉浸式系统材质。
- **FR-003**: 图片查看器底栏必须在 API 26+ 设备上应用超薄沉浸式材质（替代现有半透明纯色底），且所有按钮功能与交互保持不变。
- **FR-004**: 详情页顶部药丸按钮（返回/菜单）与右下角 FAB（收藏/下载）必须在 API 26+ 设备上应用沉浸式材质，且全部既有单击/长按交互保持不变。
- **FR-005**: 所有沉浸光感相关调用必须做 API 版本/能力运行时判断，在 API 23~25 设备上完全降级为现有样式，不产生崩溃、报错或视觉异常。
- **FR-006**: 应用沉浸式材质的组件不得同时设置背景模糊（backgroundBlurStyle/backgroundEffect）或与材质冲突的阴影属性；如需自定义阴影必须先关闭材质自带阴影。
- **FR-007**: 材质必须仅应用于局部浮动组件（底栏、药丸按钮、FAB），不得应用于整页背景、滚动列表项或视频/动图上方的组件。
- **FR-008**: 若应用级开关导致个别系统组件的默认材质不符合预期，必须能通过组件级关闭机制单独关闭该组件的材质。
- **FR-009**: 升级 SDK 版本后，应用全部既有功能（登录、浏览、收藏、下载、设置、同步等）必须保持可用，无回归。

### Key Entities *(include if feature involves data)*

- **材质配置（应用级）**: module.json5 中的全局开关声明，取值 default/enable/disable，仅 entry 模块生效。
- **组件材质参数**: 各重点组件的材质样式等级（ULTRA_THIN/THIN/REGULAR 等）、是否启用交互形变与光感反馈、是否自动反色。
- **运行时能力判定**: 设备是否支持沉浸光感的判定结果，驱动「应用材质」与「保持现状」两条渲染路径。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在 API 26+ 设备上，Toast/菜单/对话框三类系统组件 100% 呈现沉浸式材质效果；在 API 23~25 设备上，这三类组件表现与升级前完全一致（0 异常）。
- **SC-002**: 查看器底栏与详情页顶栏/FAB 在 API 26+ 设备上呈现材质效果，且其上全部按钮的功能通过率 100%（无交互回归）。
- **SC-003**: 升级后应用在 API 23~25 设备上冷启动、登录、浏览、收藏、下载全流程无崩溃（0 次 jscrash），核心页面样式与升级前一致。
- **SC-004**: 项目在目标 SDK 26 下构建成功，无因版本升级引入的新编译错误。

## Assumptions

- 用户会先在 DevEco Studio 中安装 6.2.0(26)+ SDK，再进行项目升级；实现阶段的构建验证以该 SDK 就绪为前提。
- 应用级开关采用 ENABLE 模式（而非 DISABLE/DEFAULT），与本需求「默认开启」的目标一致。
- 沉浸式材质的深浅色自适应、算力分档、系统强度配置均由系统自动处理，应用不做额外分支。
- HDS 组件（HdsNavigation/HdsTabs）不在本次范围：本项目导航基于自定义 Tabs + router。
- WebView 同层渲染场景（登录页）不做沉浸光感适配。
- 图标/图片资源不需要因材质适配而更换；文字可读性优先依赖系统自动反色，个别场景可按需开启 colorInvert。

## Open Questions

- 查看器底栏与详情页 FAB 的具体材质样式等级（ULTRA_THIN 或 THIN）及是否开启交互形变/光感反馈，在设计阶段按官方推荐默认值确定，实现后按真机效果微调。
- 应用级开关 ENABLE 后是否存在不符合预期的默认材质组件（如设置页 Select），需在验证阶段排查并按需单独关闭。
