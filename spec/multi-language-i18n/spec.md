# Feature Specification: 多语言全球化（Multi-language Internationalization）

**Created**: 2026-08-30  
**Status**: Draft  
**Input**: User description: "多语言全球化"

## Overview

ArkPix 当前全部界面文本为简体中文硬编码，仅面向中文用户。本特性将应用全面国际化：所有用户可见文本资源化为多语言（简体中文 / 繁体中文 / 英文），默认跟随系统语言，并提供应用内语言切换入口；同时网络请求的 Accept-Language 随界面语言联动，使 Pixiv 内容（tag 翻译等）与界面语言保持一致，扩大海外与繁体中文用户群体。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 跟随系统语言自动显示对应界面 (Priority: P1)

非简中用户首次安装并打开应用，系统语言为繁体中文或英文时，应用界面（页面标题、按钮、菜单、设置项、提示 toast、空态/错误态文案）自动以对应语言显示，无需任何手动设置。

**Why this priority**: 这是全球化的基础价值——海外/繁体用户开箱即用，是 MVP 必须包含的能力。仅实现此故事即可让非简中用户完整使用应用。

**Independent Test**: 将模拟器/设备系统语言分别设为简体中文、繁体中文、英文，冷启动应用，逐页检查所有界面文本以对应语言显示、无残留硬编码中文。

**Acceptance Scenarios**:

1. **Given** 系统语言为英文且应用未设置过语言偏好，**When** 冷启动应用，**Then** 全部界面文本以英文显示。
2. **Given** 系统语言为繁体中文且应用未设置过语言偏好，**When** 冷启动应用，**Then** 全部界面文本以繁体中文显示。
3. **Given** 系统语言为简体中文，**When** 冷启动应用，**Then** 界面保持简体中文显示，行为与现状一致。
4. **Given** 系统语言为应用不支持的语种（如日语），**When** 冷启动应用，**Then** 界面回退到英文显示。

---

### User Story 2 - 应用内切换界面语言 (Priority: P2)

用户在设置中手动选择界面语言（跟随系统 / 简体中文 / 繁体中文 / English），选择后界面立即切换为目标语言，无需重启应用；偏好持久化，重启后保持；选择"跟随系统"时恢复随系统语言变化。

**Why this priority**: 满足"系统语言与使用语言不一致"的用户（如系统英文但想用简中）。依赖 P1 的资源化基础，但可独立交付与演示。语言切换入口同时存在于登录页与设置页，未登录的新用户也能在登录前完成语言选择。

**Independent Test**: 在设置页切换语言为繁体中文，立即检查各页面文本变为繁体；杀掉进程重启后仍为繁体；改回"跟随系统"后界面恢复随系统语言。

**Acceptance Scenarios**:

1. **Given** 用户在设置-语言选项中选择"English"，**When** 确认选择，**Then** 当前页面及后续所有页面文本立即以英文显示，无需重启。
2. **Given** 用户已选择"English"，**When** 完全退出并重新启动应用，**Then** 界面仍为英文。
3. **Given** 用户已选择"English"，**When** 改选"跟随系统"且系统语言为简体中文，**Then** 界面立即恢复为简体中文。
4. **Given** 用户未登录且处于登录页，**When** 通过登录页的语言入口选择"繁體中文"，**Then** 登录页及后续流程文本立即以繁体中文显示，且偏好被持久化。

---

### User Story 3 - API 内容语言随界面语言联动 (Priority: P3)

Pixiv API 请求的 Accept-Language 头随当前生效的界面语言变化（zh-CN / zh-Hant / en），使 API 返回的 tag 翻译名、搜索联想等内容语言与界面一致。

**Why this priority**: 提升内容一致性体验，但不阻塞界面全球化主价值；依赖 P1/P2 确定"当前生效语言"的来源。

**Independent Test**: 界面语言为英文时浏览含可翻译 tag 的作品详情，观察 tag 翻译名为英文；切换为简中后同一作品 tag 翻译名为中文。

**Acceptance Scenarios**:

1. **Given** 界面语言为英文，**When** 发起任意 Pixiv API 请求，**Then** 请求 Accept-Language 头为英文对应值。
2. **Given** 界面语言由英文切换为繁体中文，**When** 发起新的 Pixiv API 请求，**Then** 后续请求 Accept-Language 头为繁体中文对应值。

---

### Edge Cases

- 系统语言为应用不支持的语种时回退到英文（base 资源）。
- 应用内切换语言时已打开页面、Tab 容器、路由栈中的页面需全部即时刷新为目标语言，不出现半中半英混显。
- 长文本（英文/繁体较长译文）在按钮、Tab、设置行等紧凑布局中不溢出、不截断关键信息。
- 语言切换不影响已登录状态、下载任务、书签状态等功能数据。
- 应用内语言偏好与系统语言变化冲突时，用户显式选择的语言优先于系统语言（仅"跟随系统"模式才响应系统变化）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 应用所有用户可见文本（页面、组件、菜单、对话框、toast、空态/错误态、设置项）必须资源化为多语言字符串，消除界面层的语言硬编码。
- **FR-002**: 必须提供简体中文、繁体中文、英文三套完整翻译，且任一语言下无缺失文本（缺失时回退行为可预期）。
- **FR-003**: 未设置语言偏好时，界面语言必须自动跟随系统语言；不支持的系统语言回退英文。
- **FR-004**: 设置中必须提供语言选项（跟随系统 / 简体中文 / 繁体中文 / English），切换立即生效且无需重启；登录页必须同样提供语言选择入口，使未登录用户可在登录前切换界面语言，两处入口操作同一语言偏好。
- **FR-005**: 用户的语言偏好必须持久化，应用重启后保持。
- **FR-006**: Pixiv API 请求的 Accept-Language 头必须随当前生效界面语言变化（zh-CN / zh-Hant / en 对应取值）。
- **FR-007**: 日期/时间等已本地化的显示逻辑（如作品发布日期）在多语言下保持正确格式。
- **FR-008**: 语言切换不得影响登录态、下载、收藏、同步等既有功能行为。

### Key Entities

- **语言偏好（Language Preference）**：用户对界面语言的选择，取值：跟随系统 / 简体中文 / 繁体中文 / 英文；持久化保存；默认"跟随系统"。
- **生效语言（Effective Language）**：由语言偏好解析得到的实际界面语言（zh-CN / zh-Hant / en 之一），同时驱动界面资源与 API 请求头。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 三种语言下，应用全部页面与弹窗的用户可见文本 100% 以对应语言显示，无残留简体中文硬编码。
- **SC-002**: 应用内切换语言后，界面文本 100% 在 1 秒内完成切换，无需重启应用。
- **SC-003**: 语言偏好重启后 100% 保留。
- **SC-004**: 系统语言变更后（跟随系统模式下），下次进入前台时界面 100% 匹配新系统语言。
- **SC-005**: 语言切换流程（打开设置 → 选择语言 → 界面切换完成）用户可在 3 步操作内完成。

## Assumptions

- 本期仅支持简体中文、繁体中文、英文三种语言；其余语种回退英文。
- 繁体中文采用通用繁体用词，不区分台湾/香港地区变体。
- 全部翻译由开发侧提供标准译文，不引入机器翻译运行时服务。
- 下载文件名模板、EXIF 模板、屏蔽词等用户自定义内容不做翻译，保持原样。
- WebView 登录页内的 Pixiv 网页内容由 Pixiv 站点自身语言控制，不在本期范围。
- 资源回退顺序：精确匹配语言 → 英文（base）兜底。
- 应用内语言偏好属于设备本地设置，不参与任何数据同步域（与既有"浏览相关设置为设备本地"的约定一致）。
