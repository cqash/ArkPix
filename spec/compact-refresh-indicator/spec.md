# Feature Specification: 下拉刷新指示改为顶部小条

**Created**: 2026-09-28  
**Status**: Draft  
**Input**: User description: "推荐页等的上拉刷新功能我不希望全屏占用，而是顶部一小块地方体现出在刷新就好了"

## Overview

将瀑布流列表（推荐/动态/排行/搜索/标签/收藏/用户作品等所有使用 IllustWaterfall 的页面）的下拉刷新交互从「整个列表跟随手势下移、顶部让出大块刷新区」改为「列表内容保持不动，仅在顶部悬浮一小块刷新指示」，刷新完成后自动消失。下拉手势触发刷新的交互保留不变。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 下拉刷新时列表内容不动、顶部小条指示 (Priority: P1)

用户在推荐页（或任何瀑布流列表页）顶部下拉时，列表内容不再整体跟随手指下移；下拉超过触发距离松手后开始刷新，此时仅在列表顶部悬浮显示一小块刷新指示（小菊花），数据刷新完成后指示自动消失，列表内容更新。

**Why this priority**: 这是本需求的全部核心价值——消除刷新时的全屏位移干扰，是唯一的用户故事。

**Independent Test**: 进入推荐页下拉观察列表不动、松手后顶部出现小指示、刷新完成指示消失且列表更新，即可完整验证。

**Acceptance Scenarios**:

1. **Given** 用户位于推荐页列表顶部，**When** 手指下拉，**Then** 列表内容保持原位不跟随下移
2. **Given** 下拉距离超过刷新触发阈值后松手，**When** 进入刷新状态，**Then** 列表顶部悬浮显示一小块刷新指示（小菊花），列表内容不整体下移
3. **Given** 刷新进行中，**When** 数据加载完成，**Then** 顶部指示自动消失，列表展示最新数据
4. **Given** 下拉距离不足触发阈值即松手，**When** 手指离开屏幕，**Then** 不触发刷新，无指示残留
5. **Given** 任一使用 IllustWaterfall 的页面（动态/排行/搜索/标签/收藏/用户作品），**When** 执行同样下拉操作，**Then** 行为与推荐页一致

---

### Edge Cases

- 刷新过程中列表仍可正常滚动浏览（指示悬浮不遮挡交互）。
- 列表不满一屏时下拉仍能触发刷新（与现状一致）。
- 刷新失败时指示消失、错误提示与现状一致（ErrorView/toast 逻辑不变）。
- 触底加载更多（上拉）的分页行为不受任何影响。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 下拉过程中瀑布流列表内容必须保持原位，不跟随手势整体下移。
- **FR-002**: 下拉距离超过刷新触发阈值并松手后，必须触发数据刷新，且仅在列表顶部悬浮显示一小块刷新指示（不得占用整行/整屏位移空间）。
- **FR-003**: 刷新完成后顶部指示必须自动消失；下拉不足阈值松手不得触发刷新。
- **FR-004**: 改动必须对所有使用 IllustWaterfall 的页面统一生效（推荐/动态/排行/搜索/标签/收藏/用户作品），页面级调用方无需逐个修改。
- **FR-005**: 既有功能不得回归：触底分页加载、底栏 Tab 再点回顶、刷新数据逻辑、错误重试、屏蔽过滤等保持原行为。

### Key Entities

- **刷新状态**: 未下拉 / 下拉中 / 超过阈值 / 刷新中 / 完成（沿用系统 Refresh 状态机）。
- **刷新指示**: 顶部悬浮的小型加载指示组件，仅在刷新相关状态可见。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 下拉手势全过程中列表内容位移为 0（不跟随手指）。
- **SC-002**: 刷新指示的可见区域高度不超过 64vp（一小块，非全屏/整行占用）。
- **SC-003**: 下拉刷新触发成功率与改版前一致（超过阈值松手 100% 触发，不足阈值 0% 触发）。
- **SC-004**: 全部瀑布流页面下拉刷新、触底加载、再点回顶功能无回归（手工验证通过率 100%）。

## Assumptions

- 刷新指示样式为小菊花（LoadingProgress），可带半透明药丸底衬托保证在图片上的可读性；具体尺寸/配色按系统规范默认值，不引入新的设计资源。
- 下拉触发阈值与阻尼手感维持接近现状（触发距离约 64vp 量级），不做手感调优需求。
- 「上拉加载更多」不在本次范围（用户已确认指的是下拉刷新）。

## Open Questions

- 无（需求已通过澄清确认：保留下拉手势、仅顶部小条指示、所有瀑布流页面统一生效）。
